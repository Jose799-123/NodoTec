# NodoTec — Servicio técnico de computadores

Proyecto final de **Programación Web I**, hecho con HTML, CSS y JavaScript.

**Estudiante:** [Tu nombre]
**URL:** ver `dominio.txt`

**Temática:** empresa ficticia de servicio técnico de computadores.
**Propósito:** mostrar los servicios y recibir solicitudes por medio de un formulario.
**Público objetivo:** estudiantes, hogares y pequeños negocios.

## Archivos

- `index.html`: estructura del sitio
- `estilos.css`: diseño y responsive
- `script.js`: interactividad
- `recursos/`: imágenes (`img`) e íconos (`iconos`)
- `dominio.txt`: URL del sitio publicado

## Requerimientos

| Requerimiento | Cómo se cumple |
|---|---|
| Estructura HTML | `header`, `nav`, `main`, `section` (3), `article` (3), `footer` |
| Selectores CSS | etiqueta (`body`), clase (`.boton`), ID (`#inicio`) y combinados (`nav a`, `.tarjeta > h3`, `#respuesta.error`) |
| Menú de navegación | Enlaces a Inicio, Servicios y Contacto |
| Botones | "Ver más" en cada servicio y "Enviar" en el formulario |
| Formulario | 4 campos (texto, correo, lista y área de texto), validación y mensajes de respuesta |
| JavaScript | Eventos `click` y `submit`, función `mostrarMensaje` y cambios en el DOM |
| Responsive | Media queries para tabletas (900 px) y celulares (600 px) |
